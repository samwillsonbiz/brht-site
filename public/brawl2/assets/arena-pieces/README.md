# Arena pieces

Generated with the built-in image-generation tool, then resized and encoded as WebP with alpha preserved using Sharp. Both assets are consumed by `arena-presentation.js`.

- `spike-wall.webp`: grounded wooden-and-iron barricade for Smasherton's occupied end space.
- `wind-current.webp`: upright jade-and-turquoise Wind marker for Mei. Player two uses a violet tint to preserve the existing owner distinction.

## Spike Wall prompt

Use case: stylized-concept. Asset type: polished transparent 2D fantasy fighting-game terrain sprite for Fable Fury Brawl. Primary request: one substantial physical SPIKE WALL barricade, fitting a single board space, isolated cutout on genuinely transparent background. Hand-painted cartoon fantasy illustration with bold dark ink outlines, warm wood, chunky blue-grey iron and brass rivets, exaggerated shapes, cel shading and painterly highlights, matching humorous barbarian arena artwork. A squat, thick defensive wall made of heavy stacked wooden beams clamped in dark iron, with five enormous triangular iron spikes protruding upward and outward, solid weighty support feet resting on ground. Slight three-quarter view, front surface visible, compact wide silhouette, about 1.4 wide to 1 tall, entire object and base visible with generous transparent margin. Light from upper left. Clean sharp game-ready edges. No characters, no text, no UI, no scenery, no backdrop, no icon border. Save generated asset into the project if filesystem output is supported.

## Wind prompt

Use case: stylized-concept. Asset type: transparent fantasy arena game effect sprite for Fable Fury Brawl. One placeable Wind Current marker with physical presence: three graceful curved turquoise and jade wind ribbons spiralling upward from a small circular jade floor seal, two tiny drifting pale leaves. It must read as a compact, upright magical wind vortex occupying a single arena space. Bold dark ink outlines and painterly cel-shaded fantasy cartoon game art, strong silhouette, tasteful warm ivory highlights, cyan glow only close to the object, clean edges. Modest waist-height object rather than a huge tornado; empty transparent space visible between the ribbons. Slight three-quarter view with a clearly grounded oval seal at bottom, entire object visible with margin, isolated on genuine transparent background. No characters, no text, no UI, no scenery, no frame, no fake checkerboard.
