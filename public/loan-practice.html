Formula quick guide

Enter formulas in the editor using standard Excel notation. Press Enter to move to the next calculation cell.

Basic arithmetic

=A1+B1 addition   =A1-B1 subtraction
=A1*B1 multiplication   =A1/B1 division

Cell references

B10 changes when you fill down. $B$7 is an absolute reference and stays fixed. You can also enter an answer as a plain number.

Payment function

=PMT(rate, nper, pv) calculates a constant periodic payment. Negative loan present values give positive repayments.

Other supported functions

SUM(), ROUND(), ABS(), MIN() and MAX() are available. Formulas recalculate when referenced cells change.
